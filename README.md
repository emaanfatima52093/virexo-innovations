# Virexo Innovations — Business Website

> A modern, responsive business website developed for **Virexo Innovations** as part of a Web Development internship project.

The project presents Virexo Innovations as a digital solutions studio through a clean, professional, and interactive web experience. It focuses on responsive design, accessibility, user experience, SEO fundamentals, and modern front-end development practices.

> **Project Note:** This is an internship/training concept project created for Virexo Innovations and is **not the official corporate website**.

## 📌 Project Overview

The **Virexo Innovations Business Website** is a front-end web project developed using **HTML5, CSS3, and Vanilla JavaScript**, without requiring a front-end framework or build system.

The website provides a complete business-oriented experience covering:

* Company introduction
* Services
* Working process
* Featured case study
* Client results
* Testimonials
* Frequently Asked Questions
* Contact section

The project is designed around a connected **strategy → design → development → launch** workflow.

---

## 🎯 Project Objectives

The primary objectives of this project were to:

* Develop a professional business-oriented website
* Create a responsive experience across desktop, tablet, and mobile devices
* Present digital services clearly and effectively
* Implement intuitive navigation and user interactions
* Apply semantic HTML and accessibility practices
* Implement fundamental SEO features

## 🧪 Testing & Quality Assurance

Before deployment, the following areas should be checked.

### Desktop Testing

* Navigation
* Hero section
* Service cards
* Content spacing
* Footer
* Overall visual consistency

### Responsive Testing

Test the website at different screen sizes, including:

* Desktop
* Tablet — approximately `768px`
* Mobile — approximately `375px`

Verify:

* Mobile navigation
* Responsive content layout
* Typography scaling
* Service card arrangement
* Readability
* Touch-friendly interactions

### Navigation Testing

Verify:

* Header navigation
* Mobile navigation
* Footer navigation
* Smooth scrolling
* Correct section targeting

### Browser Testing

Open browser developer tools and check the **Console** for JavaScript errors during page load and normal interaction.
